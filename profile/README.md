# VirtualBuddy Software — macOS Virtualization for Apple Silicon

## About VirtualBuddy Software

VirtualBuddy Software provides lightweight macOS virtualization for Apple Silicon Macs, enabling multiple macOS instances using native Apple Virtualization Framework. VirtualBuddy Software combines IPSW booting, recoveryOS integration, and snapshot management. VirtualBuddy Software supports testing beta releases, running legacy macOS versions, and isolating development environments. VirtualBuddy Software enables linked clones, host-guest folder sharing, and SSH port forwarding. VirtualBuddy Software includes GPU acceleration, clipboard synchronization, and resizable displays. VirtualBuddy Software is trusted by macOS developers, beta testers, QA engineers, security researchers, and Apple ecosystem professionals worldwide.

## Quick Reference for VirtualBuddy Software

| Operation | VirtualBuddy Software Action |
|-----------|------------------------------|
| New VM from IPSW | New VM → Select IPSW file |
| New VM from recovery | New VM → Download recovery image |
| Start VM | Play button |
| Force shutdown | VM → Power Off (Cmd+Shift+P) |
| Enter recovery mode | VM → Boot to RecoveryOS |
| Take snapshot | Snapshots → Take Snapshot |
| Restore snapshot | Snapshots → Select → Restore |
| Create linked clone | Right-click VM → Clone → Linked clone |
| Set shared folder | VM Settings → Sharing → Add Folder |
| Configure port forwarding | VM Settings → Network → SSH Forwarding |
| Open VM console | Double-click VM → Console tab |
| Export VM bundle | File → Export VM → .vbuddy |
